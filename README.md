# Buchhop Reinvest

Puts each Public account's spare cash into one stock you pick: every account
keeps the amount you choose (default $10) and the rest is reinvested, only when
you press Reinvest and confirm.

Download the newest version from **[Releases](../../releases/latest)**:

- Windows: `buchhop-reinvest-windows-x64.exe`
- Mac with Apple Silicon (M1-M4): `buchhop-reinvest-macos-arm64.zip`
- Mac with Intel: `buchhop-reinvest-macos-x64.zip`

After that the app updates itself from here (every download is signed).
